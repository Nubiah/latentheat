# But d'une machine frigorifique
Une machine frigorifique est construire de façon à transférer de l'énergie calorifique d'un corps froid (source froide) vers un corps chaud (source chaude), alors que l"'écoulement naturel" de la chaleur dans un échangeur se fait toujours du corps chaud vers le corps froid.

![](Pasted%20image%2020260921120542.png)
Selon l'utilisation de la chaleur transférée, la construction peut être légèrement différente.
# Cycle de réfrigération idéal
Pour un cycle de réfrigération étudié, on caractérise l'efficacité d'une machine thermodynamique avec un COP : *Coefficient of Performance*.
Pour un cycle idéal, on utilise le COP de Carnot (écrit COP$_{C}$) qui s'obtient à partir de l'équation suivante : 
$$
COP_{c}=\frac{PuissanceUtile}{PuissanceFournie}=\frac{T_{sf}}{T_{sc}-T_{sf}}
$$
Réaliser un tel cycle réversible est technologiquement impossible. Aussi il ne peut être utilisé afin d'étudier des cas concrets.
